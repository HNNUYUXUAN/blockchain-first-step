# 链上第一步

一个真正从零开始的中文区块链学习原型：输入文字 → 生成摘要 → 部署合约 → 发出交易 → 查看回执 → 回读验证 → 改一个字再验证。

**不需要钱包插件，不需要购买 ETH，不连接任何公网链。** 使用成熟的 Hardhat 本地 EVM；回执、区块、Gas 和合约状态都由实际运行的节点产生，不是假日志。

> 教学范围：本地单节点、公开测试账户、一个追加式 Solidity 合约。摘要一致不证明原文真实、身份可信或法律效力；本地链可以清空，不具有去中心化公网的安全保证。不要输入密码、个人信息或机密内容。

**当前验证状态：后端 11/11 与 DOM + 真实 EVM 流程 1/1 已通过。完整浏览器测试受本次云执行环境限制，未完成实际渲染、移动端和截图验证；不是“全端验收通过”。详见 [测试记录](docs/TEST_REPORT.md)。**

## 先懂 5 个词

| 词 | 这次实验中的意思 |
|---|---|
| 区块链 | 将交易按区块顺序记录、按既定规则执行的账本。本项目只运行一个可重置的本地开发节点 |
| 账户 / 钱包 | 地址是公开标识；签名用来授权操作。真正的钱包管理签名密钥，本项目由节点代签已解锁的公开测试账户 |
| 智能合约 | 写在 Solidity 里的小程序。部署后由 EVM 执行，这里只允许追加记录、读取记录 |
| 交易 / 回执 | 交易是发送的操作请求，拿到交易哈希还不代表成功。回执的成功状态和所在区块才说明本次执行已被收录 |
| 摘要 / Gas | SHA-256 摘要是文字的固定长度指纹；Gas 衡量链上计算与存储工作。本项目的练习 ETH 没有真实价值 |

## 快速开始：Ubuntu / Ubuntu on WSL2

要求：**Node.js 24.x 或更新的受支持偶数 LTS 版本，npm，现代浏览器**。本次验证使用 Node.js 24.19.0。Hardhat 含平台相关依赖，建议在 WSL2 的 Linux 文件系统中安装，不要把 Windows 的 node_modules 复制进 WSL。

1. 下载源码 ZIP 并解压，或者克隆本仓库
2. 在 Ubuntu / WSL2 终端进入项目目录，确认 `node --version` 显示 v24.x
3. 安装依赖并启动：

```bash
npm ci
npm start
```

4. 看到「学习实验已就绪」后，在浏览器打开 **http://localhost:4173**（或 http://127.0.0.1:4173）
5. 保持终端运行。结束时按 **Ctrl+C**

如果你还没有 Node.js，请从 [Node.js 官方下载页](https://nodejs.org/en/download)选择 Linux 的 Node 24 LTS 安装方式，再回到上述步骤。不要把任意网页提供的未知安装脚本交给 AI 直接执行。

### WSL2 小提示

- 程序仍然只绑定 WSL 的 `127.0.0.1`，不会开放到局域网
- Windows 浏览器通常可以通过 WSL2 的 localhost 转发访问；如果打不开，先在 WSL 内运行 `curl http://127.0.0.1:4173/api/state`，确认返回 `connected: true`
- 如果 WSL 内可访问而 Windows 浏览器不可访问，检查你的 WSL localhost 转发配置；不要用 `0.0.0.0` 暴露这个带已解锁测试账户的教学服务
- 本次是在 Linux 云执行器实际验证，**尚未在你的 WSL2 机器上实测**

### 安装到底改了哪里？

所有 npm 依赖在当前目录的 `node_modules/`，缓存在 `.npm-cache/`；不使用全局安装、不保存真实密钥，不写入其他项目。第一次 `npm ci` 需要联网下载官方 npm 包，之后正常启动不需要公网 RPC、API Key 或付费服务。Solidity 编译器使用已安装的 `solc` 包，不在启动时下载额外编译器。

## 10 分钟体验路线

1. **认识账户**：观察右侧返回的公开测试地址、31337 链 ID 与练习余额。这个账户的密钥公开，永远不要往它发送真实资产
2. **生成摘要**：输入一句无敏感信息的话，点击「生成摘要」。这一步在浏览器计算，没有交易、没有区块增长
3. **部署合约**：点击「部署学习合约」。等到成功回执；观察合约地址、交易哈希、区块与 Gas。部署本身是第一笔交易
4. **写入摘要**：点击「写入学习链」。等到第二张成功回执。链上存的是摘要、发送地址和区块时间，不存原文
5. **回读验证**：点击「从链上读取并验证」。服务重新调用合约读取摘要，相同文字得到「一致」
6. **体验变化**：点击「试着改一个字」，再验证。看到「不一致」，原来的链上摘要不变
7. **看懂证据**：展开「查看完整链上证据」；可下载 JSON。自己核对交易哈希、区块哈希、状态和发送地址
8. **重置实验**：Ctrl+C 停止，再 `npm start`。整条本地链清空，需要重新部署；这也是本地开发链与公网的重要区别

空格、换行、大小写以及 Unicode 的不同写法都参与摘要计算。系统不会自动 trim 或归一化；最多 1,000 个 Unicode 码点，空白输入会被拒绝。

重复点击同一次写入不会重复记录。修改输入后会产生新的请求标识，允许再次写入。同一段文字重复登记也不代表更真实。

## 这不是哪些东西

- 不是代币发行、投资、NFT 铸造或主网 DApp
- 不是完整钱包教程：你体验的是公开账户身份与节点代签，不包含个人钱包创建、私钥备份和钱包弹窗签名
- 不是法律存证服务，也不是可信时间戳服务；本地节点运营者可以重置链、操纵环境
- 不是隐私保护方案：摘要不能还原任意原文，但短词、常见句子和已知内容可以猜测后比对
- 不是防恶意管理员的生产系统。接口无身份验证，因为只面向一个人的本机实验

## 项目结构

```text
contracts/FirstProof.sol   追加式摘要合约，无更新或删除函数
server/compile.mjs        使用固定版本 solc 在内存中编译
server/ledger.mjs         ethers 调用、链限制、交易回执与幂等处理
server/index.mjs          Node HTTP 本地 API 与静态文件服务
server/config.mjs         仅本机端口与固定教学链 ID
scripts/start.mjs         一条命令启动本地节点和服务，退出时清理
public/                   中文静态界面，无前端构建步骤
tests/                   实际节点集成测试和浏览器测试
docs/AI_GUIDE.md          AI 辅助阅读、修改、验证流程
docs/ARCHITECTURE.md      数据流、接口与边界
docs/TEST_REPORT.md       实测记录与局限
evidence/                实际截图、机器可读测试证据
THIRD_PARTY_NOTICES.md    成熟工具来源与许可说明
```

本项目没有从零重造区块链。只自己写最小合约、连接服务与中文教学界面。

## 测试

```bash
npm run test:core     # 后端 + DOM逻辑，不需要浏览器
npm run test:ui       # 完整浏览器E2E，需要Chromium
npm test             # 两部分都运行；浏览器不可用时会失败
```

后端与 DOM 测试自带独立端口与真实 Hardhat 节点，不需要先 `npm start`。DOM 测试执行页面事件和数据流，但不检查像素、布局、浏览器兼容性。浏览器测试需要 Chromium；Ubuntu 上若已有 `/usr/bin/chromium` 会直接使用，也可设置 `CHROMIUM_PATH`。否则安装 Playwright 的 Chromium：

```bash
npx playwright install chromium
```

需要操作系统库的机器，可参照 [Playwright 官方安装文档](https://playwright.dev/docs/browsers)由你自行选择系统依赖安装方式。浏览器下载到 Playwright 默认用户缓存，不影响项目运行；项目运行本身不需要 Playwright 浏览器。

`npm test` 会启动测试节点和服务，全部退出后清理进程；不要与另一个测试运行同时启动。测试端口为 14173 / 18545，后端测试采用另外的隔离端口。浏览器测试将实际证据更新到 `evidence/`。

## 常见问题

**端口占用**：停止旧实验，或使用不同的本机端口：

```bash
APP_PORT=4174 CHAIN_PORT=8546 npm start
```

然后打开 http://localhost:4174 。不会接受任意公网 RPC URL。

**节点断开**：页面会明确提示、暂停链上操作；不要把等待当成功。正常启动脚本会在节点退出时同时关闭页面服务。修复后重新启动；旧链记录已经清空。

**页面刷新后原文没了**：这是预期行为。原文不写入浏览器持久存储或服务端文件；链仍运行时摘要记录还在，你可以重新粘贴原文验证。

**只重启 API**：合约地址索引与幂等缓存在 API 内存中，重启 API 后不会自动接回旧合约。对新手建议始终用 `npm start` 成对启动和停止节点、服务。

**能公开部署吗？**：不要把当前服务直接放公网。它使用已解锁的公开测试账户，只为本地学习设计。
