这次实验，你真正做了什么？
区块链：按顺序记录的账本
交易被放进区块，区块带着前一个区块的指纹。本地 EVM 按规则执行合约，产生可回读的状态与回执。
Gas：执行工作的计量
部署和写入需要计算与存储，因此消耗 Gas。这里的 ETH 只是练习余额，没有真实价值，也不需要购买。
验证：检查内容是否相同
摘要一致不证明内容真实、作者身份或法律效力。公网的共识与安全来自更多机制，本实验没有演示这些。
继续理解：本地链、测试网、主网有什么不同？
本实验只有你电脑上的一个开发节点，可随时重启清空，不是去中心化公网，也不承诺永久保存。公开测试网由多个节点运行，资产一般没有真实价值，但仍有网络与隐私风险。主网承载真实资产与手续费。本项目不会连接任何公网链。
想用 AI 辅助修改？从这三个小问题开始
  1. 请解释 contracts 中每一行 Solidity，指出摘要、发送者和时间在哪里写入
  2. 请给界面增加“复制合约地址”，保持本地链限制，并补上浏览器测试
  3. 请说明交易哈希和回执成功有什么区别，引用项目中实际判断成功的代码
一次只改一个点；先看差异，再运行 npm test。不要让 AI 接入主网、索要私钥或承诺“上链就真实”。完整步骤见 README 和 docs/AI_GUIDE.md。
